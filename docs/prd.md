| 项目 | 内容 |

## 1. 项目概述

一个 Windows 桌面常驻程序，把系统鼠标指针替换为一个精致、带 3D 质感的黑洞图标，并在鼠标周围对屏幕画面做**真实引力透镜折射**，营造"鼠标真的是一个黑洞"的观感。所有视觉参数通过图形化主界面调节，配置自动保存，程序最小化到系统托盘常驻。

### 1.1 目标
- 视觉上高度还原黑洞：纯黑事件视界 + 倾斜吸积盘 + 光晕 + 引力透镜亮环，比参考的 Grok 图标更具立体感。
- 扭曲效果是**真实折射**（基于实际屏幕像素），而非贴图模拟，且锚定在鼠标附近、随鼠标移动。
- 不牺牲鼠标可用性：命中点（hotspot）始终正确，用户能正常点击、拖拽。

### 1.2 非目标（v1.0 不做）
- 不支持 Windows 以外的平台。
- 不做多显示器 DPI 差异的高级逐屏适配（v1.0 支持多屏跟随主 DPI，后续迭代）。
- 不做鼠标点击粒子爆发、音效等附加特效。
- 不做云端配置同步 / 主题市场。

## 2. 功能需求

### F1 黑洞光标（核心）
| 编号 | 需求 | 说明 |
|---|---|---|
| F1-1 | 替换系统光标 | 隐藏系统箭头，由程序自绘黑洞（不依赖系统光标动画，帧率独立、动画平滑） |
| F1-2 | 视觉构成 | ① 中心纯黑事件视界（带极细边缘轮廓光，避免在全黑背景下"消失"）② 倾斜的吸积盘 ③ 内外多层柔光光晕 ④ 光子环（爱因斯坦环）高亮 |
| F1-3 | 3D 质感 | 吸积盘带透视倾斜；盘面有明暗渐变与内外温度差；整体有轻微自转与呼吸感 |
| F1-4 | 热点 | 黑洞正中心即命中点，鼠标功能完全正常 |

### F2 吸积盘（环）参数调节 —— 全部可实时预览
| 编号 | 类别 | 可调项 |
|---|---|---|
| F2-1 | 颜色 | 取色器自由选色（内圈色 / 外圈色）+ 发光强度 + 不透明度 |
| F2-2 | 颜色 | 双色渐变（内圈色 → 外圈色），可切换为单色模式 |
| F2-3 | 尺寸 | 环半径、环粗细、整体缩放 —— 三个独立滑块 |
| F2-4 | 姿态 | 倾斜角度（0–90°，透视圆盘感）；旋转速度（可为 0 即完全静止） |

### F3 引力透镜扭曲（真实折射）
| 编号 | 需求 | 说明 |
|---|---|---|
| F3-1 | 实现方式 | 实时抓取鼠标周围局部屏幕画面 → 交由 D3D11 像素着色器做引力透镜（光线偏折）运算 → 绘制到无边框、置顶、鼠标穿透的透明覆盖窗口 |
| F3-2 | 效果特征 | 中心全黑（事件视界），向外径向拉伸形成环状爱因斯坦环，外侧渐隐过渡回原始画面，观感参考真实黑洞照片 |
| F3-3 | 跟随 | 扭曲范围锚定在黑洞当前位置，随鼠标实时移动 |
| F3-4 | 可调 | 扭曲强度（0–3）、影响半径（60–600 px） |
| F3-5 | 性能 | 仅抓取/更新鼠标周围局部区域 + GPU 加速，目标 60 FPS，CPU 占用 < 3% |
| F3-6 | 全局开关 | 主界面与托盘均可一键关闭扭曲层（仅保留黑洞图标） |

### F4 系统光标接管与兜底
| 编号 | 需求 | 说明 |
|---|---|---|
| F4-1 | 隐藏开关 | 「隐藏系统光标」功能**可在程序内开关**（默认开启） |
| F4-2 | 智能兜底 | 检测到全屏游戏 / UWP 应用 / 远程桌面 / 锁屏等无法绘制覆盖层的场景，自动恢复系统箭头，避免出现"看不见光标"的窘境 |
| F4-3 | 兜底开关 | 兜底行为可在主界面关闭（关闭后则任何场景都强制隐藏系统箭头） |
| F4-4 | 兜底提示 | 触发兜底时托盘弹出一次气泡提示（可关闭） |

### F5 跟随物理（惯性跟随，新增）
黑洞视觉位置不强制与真实鼠标位置重合，而是以**加速度趋近**的方式追向真实光标，产生"黑洞有质量、被拖着走"的手感。

| 编号 | 需求 | 说明 |
|---|---|---|
| F5-1 | 功能开关 | 跟随效果可在主界面开启/关闭；**默认关闭**（关闭时黑洞严格贴合鼠标，保证精确性） |
| F5-2 | 加速过程 | 黑洞以弹簧-阻尼模型趋近目标点：距离越远加速度越大，起步有明显加速感 |
| F5-3 | 减速过程 | 接近目标点时按阻尼收敛平滑减速，**不允许过冲抖动**，可配置是否允许轻微过冲（阻尼比） |
| F5-4 | 最大速度限制 | 存在速度上限（px/s），鼠标瞬间大跨度移动时黑洞会被"甩在后面"并追赶；上限可调 |
| F5-5 | 自适应限速（可选） | 可勾选"距离越远限速越高"，避免大跨度移动时跟随过慢导致手感断裂 |
| F5-6 | 静止阈值 | 距离小于阈值（默认 1.5 px）时直接吸附到目标点，避免亚像素抖动与常驻运算 |
| F5-7 | 与热点解耦 | **命中点永远跟随真实鼠标位置**，黑洞滞后仅为视觉效果，不影响任何点击/拖拽操作 |
| F5-8 | 可调参数 | 刚度（Stiffness）、阻尼（Damping）、最大速度、最大加速度、静止阈值、自适应限速开关 |

> 物理模型（建议实现）：临界阻尼弹簧
> `a = k * (target - pos) - c * v`，再对 `|v|` 做 `min(vMax)` 截断、对 `|a|` 做 `aMax` 截断，按帧间隔 dt 积分（dt 上限裁剪，防止卡顿后瞬移）。

### F6 主界面
| 编号 | 需求 | 说明 |
|---|---|---|
| F6-1 | 风格 | 深色玻璃拟态（暗背景 + 微光边框），与黑洞主题一致 |
| F6-2 | 实时预览 | 内嵌预览画布，调参即时可见黑洞与环的效果（含旋转/发光），不依赖真实桌面 |
| F6-3 | 分区 | ① 外观（黑洞/吸积盘）② 透镜扭曲 ③ 跟随物理 ④ 光标与系统（隐藏、兜底）⑤ 程序设置（开机自启、重置） |
| F6-4 | 预设 | 提供若干预设（如"经典橙"、"蓝矮星"、"冷白"、"深空紫"），可一键应用并另存为自定义预设 |
| F6-5 | 操作 | 保存 / 重置当前分区 / 全部恢复默认；修改即时生效，无需重启 |

### F7 常驻、持久化与自启
| 编号 | 需求 | 说明 |
|---|---|---|
| F7-1 | 托盘常驻 | 关闭主界面窗口**不退出程序**，缩至系统托盘 |
| F7-2 | 托盘菜单 | 开关黑洞效果 / 打开主界面 / 退出 |
| F7-3 | 配置持久化 | 所有参数自动保存（用户目录 JSON），下次启动自动恢复 |
| F7-4 | 开机自启 | 主界面提供开关，写入注册表 Run 项 |
| F7-5 | 单实例 | 只允许运行一个实例，二次启动唤醒已有主界面 |

## 3. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 覆盖层渲染 60 FPS；跟随物理与渲染分离，掉帧不影响输入；CPU 占用 < 3%（空闲时 < 1%） |
| 资源 | 内存占用 < 120 MB |
| 稳定性 | 显卡驱动异常 / 抓屏失败时自动降级为"仅图标"模式并提示，程序不崩溃 |
| 兼容性 | 多显示器可跟随；支持 100%–200% DPI 缩放 |
| 安全 | 不联网、不上传任何数据；不使用驱动级挂钩 |

## 6. 关键技术风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| DXGI 抓屏在高刷/多屏下延迟 | 扭曲层与真实画面错位 | 只抓局部小区域；缓存纹理；必要时退回 BitBlt |
| 全屏独占模式（游戏）无法绘制覆盖层 | 黑洞不可见、光标消失 | F4 智能兜底自动恢复系统箭头 |
| 带 HDR / 受保护内容（DRM）窗口抓屏为黑 | 扭曲区域发黑 | 检测失败则局部关闭扭曲，仅保留图标 |
| 惯性跟随导致"手感迟钝" | 用户觉得鼠标不跟手 | 默认关闭；开启时热点仍为真实光标，并提供充分可调参数 |
| DPI 缩放导致位置偏移 | 黑洞与热点不重合 | 统一使用物理像素坐标 + Per-Monitor DPI 感知 |

## 7. 验收标准

1. 启动后系统箭头消失，屏幕上出现带旋转吸积盘的黑洞，且黑洞中心可正常点击任意 UI。
2. 移动鼠标时，周围画面出现径向拉伸的透镜扭曲，且扭曲随鼠标平滑移动；`LensStrength=0` 时无扭曲。
3. 主界面改动颜色/半径/粗细/倾斜/转速，桌面黑洞**即时**变化，预览区同步。
4. 关闭「隐藏系统光标」后系统箭头立刻恢复；进入全屏游戏时箭头自动恢复。
5. 开启惯性跟随并设较低限速后，鼠标快速甩动时黑洞明显落后并加速追赶，停手后平滑减速收敛、无抖动；鼠标点击位置始终正确。
6. 关闭主界面后程序仍在托盘运行；重启电脑（开启自启）后自动生效且保留上次配置。
7. 1080p 桌面下持续 5 分钟使用，帧率稳定 ≥ 55 FPS，CPU 占用 < 3%。

## 9. 待定事项

- 抓屏方案最终选型（DXGI Desktop Duplication vs BitBlt）在 M3 实测后确定。
- 吸积盘是否叠加噪声纹理（ turbulence ）以增强 3D 感，M2 视效果决定。
- 是否提供"点击时事件视界轻微膨胀"的微交互（v1.1 候选）。
