## 1. 背景与目标

### 1.1 为什么要改
v1.0 已完整实现（配置持久化、托盘常驻、光标接管与兜底、惯性跟随、静止游荡、出现/消失动画、主界面与预设）。
但**黑洞本身的观感不达标**：v1 用的是 2D 解析近似（每像素一次位移采样 + 手绘椭圆盘 + 高斯光子环），
是「画得像黑洞」，而不是「算出来的黑洞」。

参考项目 **singularity 0.4.0**（Rust/WGPU，MIT，源自 `s0xDk/ghostty-blackhole`，后者按
Eric Bruneton《Real-time High-Quality Rendering of Non-Rotating Black Holes》实现）
证明了在桌面覆盖层上做**逐像素零测地线积分**是可行的，且观感差距巨大。

**v2 的目标：把渲染核心换成测地线积分，同时完整保留 v1 已有的产品能力与行为。**

### 1.2 开发顺序与粒度（用户指定）
**先改渲染核心，再修 bug。** 理由：核心换掉后部分 bug 的形态与复现条件会变，
先修可能白修或需要返工。因此本 PRD 把「渲染核心」列为 M1，「已知缺陷修复」列为 M3。

**粒度**：M1 拆为 **M1.1 – M1.8** 共 8 个小步，其余里程碑同样拆到子步骤
（详见 `plan-v2.md` 第 2 节「步骤总览」）。每个子步骤单独加测试、测试全绿后再进入下一步。

## 2. 产品定位（不变，且明确排除）

### 2.1 定位
**它是鼠标光标**，不是桌面装饰，也不是屏保：
- 始终跟随光标，**不会消失**、不会变成空闲才出现的装饰；
- 命中点永远是真实鼠标位置，所有跟随/游荡/缩放动画**只影响视觉**；
- 透镜扭曲只是光标周围的视觉层，不改变任何输入行为。

### 2.2 明确不做（对比 singularity 的差异）
- **不做** singularity 那种应用形态：不开全屏新窗口、不「显示桌面后消失」、不做自动漫游为主的默认行为；
- **不做** screensaver / 空闲才出现（v1 的「静止游荡」是光标附近的微漂移，与之不同）；
- **不做** macOS / Linux 支持；
- **不做**联网功能（v1 也没有）；
- **不做**驱动级挂钩。

### 2.3 许可
singularity 与 ghostty-blackhole 均为 MIT。移植只需在「关于」页与源码注释中署名。

## 3. 功能需求

### F1 渲染核心：逐像素零测地线（核心改造）

每像素在 3D 中数值积分光子测地线（leapfrog kick-drift-kick），
加速度采用 Binet 形式 `a = -(3/2)·h²·x / r⁵`（等价精确 Schwarzschild 偏折）。
必须自然涌现以下现象，不允许用贴图/手绘伪造：

| 编号 | 现象 | 说明 |
|---|---|---|
| F1-1 | 真阴影 | 撞击参数 < `b_crit = 3√3/2 ≈ 2.598 r_s` 的光线旋进视界，形成纯黑阴影 |
| F1-2 | 爱因斯坦环 + 镜像二次像 | 逃逸光线反投影到桌面「天空平面」，出现环状拉伸与**倒转的二次像** |
| F1-3 | 薄盘多次穿越 | 倾斜薄盘可被同一条光线穿越多次，**远侧盘面从阴影上方/下方绕过去**（星际穿越 Gargantua 造型的关键） |
| F1-4 | 黑体色温 | Shakura-Sunyaev 温度剖面 + Tanner Helland 黑体拟合；内圈高温偏白、外圈低温偏红 |
| F1-5 | 相对论多普勒 + beaming | 真多普勒因子 `g`（含引力时间膨胀 `sqrt(1-1.5/r)`）与 `g^beam` 集束，一侧显著更亮 |
| F1-6 | 开普勒转速 | 条纹转速 `∝ r^-1.5`，内圈明显快于外圈 |
| F1-7 | HDR + tonemap | 盘光按 `1 - exp(-emit·expo)` 压缩，高光不糊成一团 |
| F1-8 | 远场解析弱偏折 | 远处用解析公式，与积分区在交界圆上位移差 <1%，**不得有接缝**。<br>⚠️ 实测偏差约 **2.8% / 0.15px**（亚像素、肉眼不可见）—— 拟合系数是针对参考实现的积分器拟合的，与我们的有约 3% 系统差，详见 §9 R8 |
| F1-9 | 轻微色差 | 蓝比红弯得多一点（`ab ≈ 0.035`） |
| F1-10 | 透镜星场（可选） | 按弯折后的光线方向索引的程序化星点，`star` 控制强度 |
| F1-11 | Kerr 自旋 | spin 0–0.98：Kerr-Schild 精确测地线，ISCO 收缩使盘贴住阴影、非对称帧拖拽漩涡；**spin < 0.005 时走 Schwarzschild 快速路径** |
| F1-12 | 积分步数可调 | 质量档位控制：低 24 / 中 48 / 高 88（Kerr） |

## 5. 参考实现对照（v1 → v2）

| 能力 | v1（现状） | v2（目标，对齐 singularity） |
|---|---|---|
| 算法 | 2D 解析近似，单次位移采样 | 3D 测地线数值积分（48/88 步 leapfrog） |
| 阴影 | 黑圆 + 高斯边 | `b_crit` 真阴影 |
| 透镜 | 拉伸 | 爱因斯坦环 + 镜像二次像 + 远场解析无缝 |
| 盘 | 单张椭圆贴图 | 薄盘多次穿越 + 远侧光弧 |
| 颜色 | 双色 lerp | 黑体色温（Shakura-Sunyaev） |
| 相对论 | 假多普勒系数 | 真多普勒 + beaming + 引力时间膨胀 |
| 转速 | 整体匀速 | 开普勒 `∝r^-1.5` |
| 合成 | 直接相加 | HDR + tonemap |
| 自旋 | 无 | Kerr（ISCO 收缩 + 帧拖拽漩涡） |

> 第 10 条（截图补偿）已在**实机**验证：合成点平均亮度 12.2 vs 远处 128。

1. **阴影**：渲染结果中心区域像素 RGB 全黑、alpha 不透明（WARP 实渲像素断言）。
   ⚠️ 已确认的物理事实：**侧视盘（incl≈1.52）时阴影中心并非纯黑** —— 中心视线会在
   `z≈+3 r_s` 穿过盘的近侧并产生发光，即 Gargantua 造型里横穿阴影的那条亮带。
   断言时需避开该亮带（或改用接近正视的倾角）再判纯黑。
2. **爱因斯坦环**：环位置亮度显著高于同位置的原始背景采样。
3. **镜像二次像**：阴影外侧特定采样点能取到被弯折/翻转的背景内容（与未开启透镜时不同）。
4. **远侧光弧**：阴影正上方采样点亮度高于盘外侧背景（证明薄盘多次穿越存在）。
5. **色温**：1500K 时 R>B；15000K 时 B>R（黑体拟合方向正确）。
6. **Kerr**：spin=0.9 时 ISCO 半径小于 spin=0（盘更贴住阴影）。
7. **帧率无关性**：TargetFrameRate = 60 / 165 / 240 时，同样的鼠标移动下黑洞跟随位移一致。
8. **帧率达标**：设为 165 时实测 ≥150 fps。
9. **自排除捕获**：连续两帧抓屏内容不因覆盖层自身输出而变化（无镜像累积）。
10. **截图补偿**：模拟全屏位图进入剪贴板后，输出图像中心区域含黑洞。
11. **不回退**：v1 的 171 项测试中与新体系无关的部分全部保持通过（配置/光标/跟随/游荡/动画/预设机制）。
12. **实机**：桌面截图肉眼确认黑洞造型（真阴影 + 环 + 远侧光弧 + 透镜）。
