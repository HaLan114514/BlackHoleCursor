## 4. 需求条目

### V4-1 新增「预设」页面

- 左导航新增一项「预设」，位置在「外观」之下。
- 页面内**两个分组**，各带小标题：
  - **内置**（8 个，来自 `LookPresets.Names`）：只读，只能「应用」。
  - **我的**（`presets.json`）：可应用 / 重命名 / 覆盖保存 / 删除 / 导出。
- 应用预设沿用 M5.2 的行为：**先 `BeginPresetFade()` 再增量补丁应用**（`AppearanceView` 现在的顺序，别在搬移时弄反）。
- 保留现有底线：内置名不允许占用、删除需二次确认。

### V4-2 自定义预设的管理能力

| 操作 | 行为 |
|---|---|
| 另存为 | 输入新名字 → 保存（内置名 / 空名拒绝并提示） |
| **覆盖保存**（新） | 选中「我的」里某个预设 → 用当前设置覆盖它（提示「将覆盖『X』」并确认） |
| **重命名**（新） | 改名字；新名字不得与内置或其它自定义重名 |
| 删除 | 二次确认（沿用现在的行为） |

- 以上全部落在 `PresetService`（Core 层，**可单测**），UI 只做入口。

### V4-3 预设导出 / 导入

- **导出**：选中「我的」里的预设 → 存成 `*.json`（文件名默认用预设名）。
- **导入**：选文件 → 解析 → 合并进 `presets.json`：
  - 重名 → **提示「覆盖 / 另存为」**（不静默覆盖，也不直接丢弃）；
  - 文件损坏 / 不是预设文件 → 提示一次，**不崩、不破坏现有 presets.json**；
  - 内置名出现在导入文件里 → 忽略（与 Load 的现有规则一致）。
- 导入导出走 `PresetService`，文件格式带版本号字段（见风险 R1）。

### V4-4 页面重分为 6 页

| 页 | 内容 |
|---|---|
| 外观 | 大小 / 颜色 / 盘形 / 相对论外观（**预设卡片移走**，**透镜开关移走**） |
| **预设** | V4-1 ~ V4-3 |
| **渲染与性能** | 曝光 / 星空强度 / 星云强度 / 星云色调 / 氛围流速 / 积分步数（质量档） |
| 引力透镜 | 启用桌面扭曲（**唯一入口**）+ 抓屏状态（见下） |
| 跟随与动效 | 惯性跟随 / 静止游荡 / 阻尼手感预设 / **出现·消失动画**（从「程序设置」页搬来） |
| 系统与程序 | 隐藏系统光标 / 智能兜底 / 运行状态 / 开机自启 / 截图补偿 / 配置文件 |

**引力透镜页不再空**：除了开关，补上**抓屏状态**（是否降级 / 当前帧率 / 自动档步数）——
这些信息主界面状态行里已经有了，搬到这页正好让「透镜 + 抓屏」这件事有地方看。

### V4-5 修掉 `LensEnabled` 重复开关

外观页「渲染」组里那个「引力透镜」开关**删除**，只保留引力透镜页的「启用桌面扭曲」。
⇒ 必须有断言锁住「每个设置项在界面里**恰好出现一次**」（见 §7）。

### V4-6 程序图标（`.ico`）

- 由 `IconFactory` 以 **256px** 渲染底图 → 生成含 **16 / 32 / 48 / 256** 四个尺寸的 `.ico`，
  作为**资源文件**放进 `src/BlackHoleCursor/Resources/`（不依赖运行时绘制）。
- `csproj` 设 `<ApplicationIcon>` ⇒ exe 图标、任务栏、Alt+Tab、窗口标题栏全部生效。
- 生成脚本 / 一次性工具放 `tools/`（图标是产物，不是每次编译都要重画）。

### V4-7 托盘图标（两张）

- 彩色（启用）/ 灰暗（禁用）两张，切换「启用黑洞」时换图标（现在 `UpdateTrayIcon()` 的位置）。
- 尺寸取 64（托盘在高 DPI 下会缩到 16/20/32，多尺寸已在 .ico 里）。

### V4-8 安装包与版本号

- `installer/BlackHoleCursor.iss`：加 `SetupIconFile`（安装程序自己的图标）；
  `UninstallDisplayIcon` 现在指向 exe，设了 `ApplicationIcon` 后自动生效。
- 版本号：主界面左上角 **「CURSOR v1.0」→「CURSOR v4.0」**，iss 里 `AppVersion 1.0.0` → **`4.0.0`**
  （✅ 你已确认要改；安装包输出文件名会跟着变成 `BlackHoleCursor-Setup-4.0.0`）。

## 7. 验收标准

| 项 | 标准 |
|---|---|
| 预设页 | 内置与「我的」**视觉上明确分开**（分组标题）；内置不可改名 / 删除 |
| 重命名 / 覆盖 / 删除 | 内置名拒绝、空名拒绝、重名拒绝；删除二次确认 |
| 导出 / 导入 | 导出 → 导入回来一致；导入重名给「覆盖 / 另存为」；导入损坏文件**不崩且不破坏现有预设** |
| 6 页 | 导航 6 项；每个设置项在界面里**恰好出现一次**（自动断言，见下） |
| 无遗漏 | 现在界面上能调的每一項，在 v4 里都能找到（自动断言，见下） |
| 图标 | exe 属性里有图标；任务栏 / Alt+Tab / 窗口标题栏显示它；托盘在启用 / 禁用下**两张不同图标** |
| 回归 | `dotnet build -c Release` **0 警告 0 错误**；`dotnet test` 全绿；实机跑一遍无异常 |

**两条自动断言（防止搬控件时搬丢 / 搬重）**
1. **无重复**：扫描所有 View 的 XAML，统计 `{Binding X}` 的属性名，同一个属性不得出现两次。
2. **无遗漏**：`SettingsModel` 里所有「用户可调」的属性，必须在某个 View 的 XAML 里出现至少一次
   （这条能直接把 V4-5 那个重复开关抓出来，也能防止拆页时漏搬控件）。
